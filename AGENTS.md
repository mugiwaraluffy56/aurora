# Repository Instructions

- After every completed build phase or work request, commit and push the code.
- Commit subjects must be one line, human-written, and concise.
- Use `git commit -s -m "message"` so Git adds the signoff trailer from the current repo git config.
- Do not mention AI, assistants, bots, or generated code in commit messages.
- Keep each phase buildable before committing.
- Use `main` as the default branch.
