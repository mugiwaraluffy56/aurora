# Repository Instructions

- After every completed build phase or work request, commit and push the code.
- Commit messages must be one line, human-written, and concise.
- Every commit message must include the user signoff based on the current repo git config: `Signed-off-by: $(git config user.name) <$(git config user.email)>`.
- Do not mention AI, assistants, bots, or generated code in commit messages.
- Keep each phase buildable before committing.
- Use `main` as the default branch.
